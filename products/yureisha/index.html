Yureisha

A native macOS orchestrator for Claude Code agents.

Yureisha runs a small software company of agents for you. You define departments, roles and policies per project, and it keeps your Claude Code agents working: dispatching tickets, continuing stalled runs, choosing validation by expected value, and bringing decisions to you only when they are one-way doors.

  • Drives your own Claude Code installation; your organisation, policies and roadmap live in your repos as plain files.
  • Steel threads and tracer bullets: progress is shown as working end-to-end paths instead of closed tickets.
  • Humans only for one-way doors: money, credentials, external commitments, irreversible data and legal.
  • An append-only event log records every dispatch and decision, with the reasons.

Paid app, planned for the Mac App Store.
